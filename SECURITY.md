# Security Policy

## Supported Versions

Security updates are actively applied to the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3   | :x:                |

## Reporting a Vulnerability

We take the security of Opsora SRE seriously. If you discover a security vulnerability, please do **NOT** open a public GitHub issue.

Instead, please send an advisory email directly to **hello@johnokyere.xyz** with:
- A description of the vulnerability.
- Steps to reproduce the issue or a proof-of-concept.
- Potential impact and mitigation ideas, if known.

### Response Timeline
- **Initial Acknowledgment**: Within 24 hours.
- **Triage & Assessment**: Within 48 hours.
- **Fix & Patch Deployment**: Target within 5 business days for critical issues.

We appreciate your responsible disclosure and will credit security researchers in our release notes upon fix deployment.
